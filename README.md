# Assistente TCC ABNT 🤖📚

## Sobre o projeto

O Assistente TCC ABNT é um bot desenvolvido para o Discord com o objetivo de auxiliar estudantes na organização e elaboração de Trabalhos de Conclusão de Curso (TCC).

O projeto busca facilitar etapas do desenvolvimento acadêmico, oferecendo recursos de organização, orientação e geração de documentos.

## Funcionalidades

- Cadastro e organização de projetos de TCC.
- Registro de informações do aluno e orientador.
- Integração com inteligência artificial.
- Auxílio na elaboração de trabalhos acadêmicos.
- Geração de documentos Word.
- Comandos administrativos e de acompanhamento.

## Tecnologias utilizadas

- JavaScript
- Node.js
- Discord.js
- PostgreSQL
- Google Gemini AI
- Microsoft Word (.docx)
